QuizzyVerse
A universe of trivia fun – One category at a time!

📚 Overview
QuizzyVerse is a full-stack trivia quiz game built with the MERN stack (MongoDB, Express, React, Node.js). It features four categories of knowledge — Movies, Sports, Geography, and History — each containing 50 curated questions. Every game session randomly selects 7 questions from a chosen category and challenges players with a countdown timer and real-time scoring.

🚀 Features
🔥 4 Categories: Movies, Sports, Geography, and History

🎲 Randomized Gameplay: 7 random questions from a set of 50 per category

⏱️ Per-Question Timer: 15-second timer to answer each question

🧠 Multiple Choice Questions

🧾 Live Scoring System

🏁 Final Score Display at End

⚙️ Built with the MERN Stack

🛠️ Tech Stack
📦 Backend
Node.js

Express.js

MongoDB with Mongoose

💻 Frontend
React.js

Axios for API calls

React Router for navigation
🎯 Game Flow
Home screen displays category choices.

User selects a category (e.g., History).

7 random questions are fetched from MongoDB.

Timer starts for each question.

After all 7 questions, score is displayed.

Option to retry or choose a different category.
